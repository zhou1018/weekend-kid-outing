# 视觉卡片 JSON 输入规范

`scripts/render_outing_card.py` 的输入。把 Phase 3/4 抽出的方案字段映射到下面结构，写成 JSON 文件后调用脚本。

## 字段表

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `label` | string | 否 | 顶部小标签，默认「方案 1」；多方案时写「方案 2」「雨备」等 |
| `title` | string | 是 | 方案名，最多约 12 字，超长自动缩字号 |
| `score` | number | 否 | 适配度 0–100，显示在右上绿色徽章 |
| `meta` | string[] | 否 | 副信息，最多 2 行（区域/通勤/费用/天气适配） |
| `timeline` | [string,string][] | 否 | 时间线，最多 5 条，格式 `["09:00", "做什么"]` |
| `tags` | string[] | 否 | 底部标签，最多 3 个（真实链接/一键导航/雨备等） |
| `notes.highlight` | string | 否 | 亮点，一行 |
| `notes.caution` | string | 否 | 注意事项，一行 |
| `bg` / `ink` / `muted` | string | 否 | 配色 hex，一般不改 |

## 示例

```json
{
  "label": "方案 1",
  "title": "东湖 · 飞鸟世界",
  "score": 98,
  "meta": [
    "半户外半室内 · 地铁 8 号线 · 5 岁适龄",
    "上午晴 / 下午室内躲雨 · 免费 + ¥59 起"
  ],
  "timeline": [
    ["09:00", "东湖绿道骑行 · 草坪野餐"],
    ["10:00", "飞鸟世界 · 赶剧场"],
    ["13:30", "海洋世界 · 室内躲雨"],
    ["16:00", "返程"]
  ],
  "tags": ["真实来源链接", "一键导航", "雨天备选"],
  "notes": {
    "highlight": "零距离喂鹦鹉羊驼 · 海底隧道鱼群",
    "caution": "周一休演 · 周末停车紧张"
  }
}
```

## 调用

```bash
python3 <skill目录>/scripts/render_outing_card.py plan.json --out card.png
```

输出固定 1080×1440 竖版 PNG，可直接发家庭群或剪进视频。

## 铁律映射

- `score` 必须来自 Phase 4 的加权计算，不可凭感觉写。
- `meta` / `notes` 中涉及费用、营业、时效的内容必须来自检索结果；不确定写「需核实」，不要编造。
- 卡片是**摘要**，来源 URL 在对话正文里给出（卡片底部标签只是提示），不要把长 URL 塞进图片。
