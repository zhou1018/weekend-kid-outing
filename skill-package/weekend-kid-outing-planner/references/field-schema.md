# 字段抽取 Schema + 适配度评分

本文件供主流程 Phase 3/4 使用。AI 对每个候选地点/活动按此抽取字段并打分。

## 一、结构化字段（每条候选必抽）
| 字段 | 说明 | 取值/示例 |
|---|---|---|
| name 名称 | 地点/活动名 | 上海辰山植物园 |
| type 类型 | 分类 | 自然户外 / 博物馆科技馆 / 农场采摘 / 乐园游乐 / 公益免费场馆 / 亲子市集 / 其他 |
| district 区域 | 城市内区位 | 松江区 |
| ageFit 适龄 | 是否适配档案年龄 | 适配 / 部分适配 / 偏龄（并注明适合几岁） |
| distance 距离 | 相对城市中心或用户区的通勤 | 自驾约 40min / 未知（检索未给则标未知） |
| cost 费用 | 花费 | 免费 / 30 元 / 100–200 元 / 未知 |
| duration 时长 | 半日或一日 | 半日 / 一日 |
| weatherFit 天气适配 | 与本周天气的匹配 | 户外-晴好 / 户外-多云可 / 室内-雨备 / 高温规避 |
| highlights 亮点 | 2–4 条吸引点 | 温室热带植物、儿童探索园、大片草坪 |
| tips 注意事项 | 预约/停车/装备/安全 | 需提前预约、停车紧张、带防蚊 |
| source 来源链接 | **必须真实**，来自检索或用户粘贴 | https://... |
| freshness 时效 | 近期是否仍有效 | 有效 / 需核实（活动类必核本周仍办） |
| score 适配度 | 0–100，见下 | — |

## 二、适配度评分（0–100，权重合计 100）
| 维度 | 权重 | 打分逻辑 |
|---|---|---|
| 年龄适配 | 25 | 完全适龄=25；部分适配=15；偏龄=5 |
| 天气适配 | 25 | 与本周天气完美匹配（如晴天推户外/雨天推室内）=25；一般=12；相悖（雨天推纯户外无雨备）=0 |
| 距离/通勤 | 20 | 步行/30min 内=20；1h 内=12；大于 1.5h 或未知=6 |
| 预算 | 15 | 符合预算档=15；略超=8；明显超/未知=4 |
| 时效/新鲜度 | 15 | 近期有效且来源新=15；需核实=7；陈旧=3 |

- 综合 = 各维度得分求和。
- 排序：按 score 降序，取 Top 3–5。
- 若有「雨备/高温规避」标记，在推荐理由中显式说明，并优先于无防护的同类方案。

## 三、时效核验规则（硬性）
- 帖子发布时间超过 3 个月：不得作为唯一依据，须配合其他近期来源或标「需核实」。
- 活动类（市集/展/节庆）：必须核实"本周/本月是否仍举办"，不能确定标「需核实」。
- 场馆类：核实"是否仍营业/是否需要预约"，不能确定标「需核实」。
- 距离、费用若检索未给出，标「未知」，**禁止估算填充**。

## 四、覆盖与合规备注
- 小红书/抖音**站内**内容：纯联网检索覆盖弱（仅部分被搜索引擎收录），命中少属正常，须在输出末尾如实声明。
- 用户粘贴原帖链接时：仅解析其公开可见信息做摘要，不存全文、不二次分发。
